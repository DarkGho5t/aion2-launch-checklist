# AION 2 General Launch Checklist

A free, mobile-friendly AION 2 launch checklist for Main Character + Alts.

## Deploy with GitHub Pages

1. Create a new **Public** GitHub repository.
2. Upload all files from this folder.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose:
   - Source: **Deploy from a branch**
   - Branch: **main**
   - Folder: **/ (root)**
5. Save.
6. GitHub will give you a URL similar to:
   `https://YOUR-USERNAME.github.io/YOUR-REPOSITORY/`

## Features

- Arabic / English
- Arabic is the default language
- Dark / Light mode
- Responsive mobile layout
- Interactive checklist
- Progress tracking
- Progress is saved locally in the user's browser
- No server or database required
- Free to host on GitHub Pages

## Important

The checklist is client-side. Each person's checked tasks are saved on their own device/browser and are not shared with other players.

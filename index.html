🚨 The Day-1 Rule

Do NOT try to min-max everything on Day 1.
all characters → 22 → Main → 45 → 5 Duty Quests → stop. The first-week plan is different from Early Access because you only have about two days before the assumed Wednesday reset.
Golden rule: Main first. If an activity is server-wide/shared, never consume it on an alt before the Main gets it.

🟢 DAY 1 — Launch Day

Exact order recommended by the plan for the launch.

Phase 1 — Get ALL characters to Level 22

  • 🎮 Main Character → Level 22At Level 22, Odyle Energy unlocks and starts recharging.
  • 🧑 Alt 1 → Level 22Unlock Odyle Energy recharge on this character too.
  • 🧑 Alt 2 → Level 22Same goal: reach 22 and start its independent energy recharge.
Why 22? Odyle Energy is independent per character. getting every character to 22 first so all of them start recharging as early as possible.

Phase 2 — Main to Level 45

  • 🎮 Main Character → Level 45This unlocks Nightmare Dungeons and Duty Quests.

Phase 3 — The 5 Duty Quests

  • Complete Duty Quest #1
  • Complete Duty Quest #2
  • Complete Duty Quest #3
  • Complete Duty Quest #4
  • Complete Duty Quest #5
Duty Quests are once per server. Do all 5 on the Main. Do NOT waste them on Alts.

🛑 Day 1 Finish Line

Once the 5 Duties are done, the plan considers Day 1 complete. Do not feel pressured to finish all side content or reach 1400 today.

🔵 DAY 2 — Day 2

This is the important catch-up day before the assumed Wednesday reset.

Priority 1 — Do the time-sensitive weeklies

  • 🎮 Main — Ascension TrialHighest priority for the short first-week window.
  • 🎮 Main — Daily Dungeon ticketsThese weekly tickets reset at the end of the week.
Do these before getting lost in side content. The plan specifically puts Ascension Trial + Daily Dungeons at the top for the short launch window.

Priority 2 — Weekly resources

  • Craft available Odyle Energy — server craft(s)The system provides server-side and per-character Odyle Energy crafts. Only do them if you have the required resources.
  • Craft available Odyle Energy — Main character craft(s)
  • Craft available Odyle Energy — Alt 1 character craft(s)
  • Craft available Odyle Energy — Alt 2 character craft(s)
  • Subscriber Shop — buy Odyle EnergyOnly if you have the subscription and the needed currency.
  • Subscriber Shop — buy Unknown Fisher Challenge ticketsThese add Daily Dungeon attempts.
  • Subscriber Shop — buy Soul CrystalsImportant for Genus progression .

Priority 2 — Main daily

  • 🎮 Main — 5 Duty QuestsAgain: server-wide, so Main only.

Priority 2 — Buy the weekly quest scrolls

  • Buy all available PvE weekly quests (up to 12/server)They can stack; buying them is the important part. You do not have to finish all immediately.
  • Buy all available PvP weekly quests (up to 20/server)Also stackable. Buy before reset; complete later if needed.

🧑‍🤝‍🧑 Alts — Day 2

Only do alt content after the Main's critical content is safe.

  • Alt 1 — Ascension Trial Ascension Trial can be done on every character.
  • Alt 2 — Ascension Trial
  • Alt 1 — Battlefield wins (if time)Battlefield victory rewards are per character.
  • Alt 2 — Battlefield wins (if time)
Do not do Duty Quests on Alts. They are once per server. The same principle applies to other explicitly server-wide systems.

🌙 Nightmare Tickets

  • Check Main Nightmare ticketsNightmare unlocks at 45 and recharges per character.
  • Use available Nightmare attempts if appropriateFor a normal full week the plan recommends letting tickets accumulate and getting stronger first. With only two days, don't let useful tickets expire, but prioritize the urgent content first.

🎮 MAIN — 1400 Item Level Push

This is the main progression goal after the urgent Day-2 weekly content.

Finish Main Progression

  • Finish Main StoryIf anything remains after reaching 45, finish it.
  • Complete Green / Side Quests these provide major progression, skill points and gear.
  • Clear Sealed Dungeons
  • Clear Strongholds / Question Marks completing the relevant question-mark content on the map.
  • Collect useful FeathersFeathers can be synchronized between characters, so you do not need to repeat the same collection on every alt.
  • Progress Daevanion Board
  • Collect Skill Points / progression rewards
  • Equip useful gear upgrades
Target: 1400 Item Level. 1400 as the requirement for Vakron Sky Island .

🏝️ Once Main reaches 1400

  • Unlock / enter Vakron Sky IslandMain dungeon goal for the first-week progression path.
  • Use Odyle Energy for valuable dungeon lootAvoid wasting energy on low-value runs; the goal is useful gear progression.

⚔️ Weekly / Event Checklist

Battlefield

  • Main — Battlefield Victory #1
  • Main — Battlefield Victory #2
  • Main — Battlefield Victory #3Three victory rewards per week, per character .

Shugo Festival

  • Check for Shugo Festival event popupUnlocks at level 13. Two keys recharge daily, max 14. The system is shared across characters, so use the event/reward on Main.
  • Use Shugo Festival key when worthwhile

Abyss Corridors

  • Check Wednesday/Saturday Artifact Siege outcome
  • Run available Abyss Corridor(s)Can be done on Main and Alts. Gives Kina and Abyss Points.

World / Field Bosses — Optional

  • Check map for upcoming Field BossesDo not set alarms just for these. If you're online and one is spawning, participate when convenient.

💰 Supply Requests — Optional Money Check

These are not mandatory just because they exist.

  • Check Emergency / Daily Supply Requests
  • Check Weekly Supply Requests
  • Check Seasonal Crafts
  • Decide whether selling materials is more profitable than feeding themThe plan warns that market prices can make some requests inefficient. You do NOT have to complete every request.
Rule: Before submitting expensive materials, check their market value. Sometimes selling them is better than completing the request.

📋 Systems Reference — Don't Forget These

🔋 Odyle Energy

  • Unlocked at Level 2215 every 3 hours; 120/day; storage cap described in the plan as 840.
  • Independent per character
  • Use for dungeon loot cubesThe plan describes 40 Odyle per normal cube opening; subscription allows an additional opening for 80 total.

🎮 Shugo Festival

  • Unlocks at Level 13
  • 2 keys/day, max 14
  • Shared across characters — use Main

💀 Nightmare

  • Unlocks at Level 45
  • 2 tickets/day, max 14
  • Independent per character

📅 Weekly Reset Strategy

  • Do urgent weekly content before reset
  • Buy weekly shop/quest items before reset
  • Don't waste time trying to finish optional content before critical content

🚦 Quick Decision Tree While Playing

Where am I in the plan?

1. Any character below 22? → Get it to 22.
2. All 3 at 22 but Main below 45? → Main to 45.
3. Main 45 and today's 5 Duties unfinished? → Do Duties.
4. Day 1 and Duties done? → You're done with the mandatory launch route. Save yourself for Day 2.
5. Day 2 and Ascension/Daily Dungeon unfinished? → Do those first.
6. Those done? → Crafts + Shop + Duties + weekly quest purchases.
7. Main weekly essentials safe? → Alts' Ascension/Battlefields/Nightmare as appropriate.
8. Still have time? → Main side content → push toward 1400.
9. Main reaches 1400? → Vakron Sky Island / valuable dungeon progression.

🧠 Don't Waste These

  • Don't spend server-wide Duty rewards on an Alt.
  • Don't rush optional side content before the Day-2 priority content.
  • Don't assume every activity is per-character.Check whether it is server-wide/shared before using it on an Alt.
  • Don't force Supply Requests when materials are overpriced.
  • Don't panic about 1400 on Day 1. 22 → 45 → 5 Duties on Day 1.
